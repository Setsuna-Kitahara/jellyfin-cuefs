1. 选镜像

完整版镜像不自带 TAK 解码库：装好后需要你自己下载 tak233.zip 并导入（个人/非商业用途）。
官方镜像在 GHCR 与 Docker Hub 各有一份、内容相同、匿名可拉；Docker Hub 上把 ghcr.io/setsuna-kitahara/cuefs 换成 kitaharasetsuna/cuefs 即可。
